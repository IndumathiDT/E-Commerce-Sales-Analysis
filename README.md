## Description
This project features an interactive Power BI dashboard built to analyze e-commerce sales performance. It highlights core key performance indicators (KPIs) including total sales amount, profit, quantity sold, and average order value. Powered by Power Query for data transformation and DAX for custom calculations, the report uncovers actionable sales trends and profitability insights.

### Key Features:
- **KPI Metrics**:

  - Total Sales Amount
  - Total Profit
  - Total Quantity
  - Average Order Value

- **Visualizations**:
  - **Monthly Profit Trends**: Monthly profit performance paired with a quarterly slicer.
  - **Sales Amount by Category**: Breakdown of sales performance across product categories.
  - **Sales Amount by Customer**: Customer-level sales contribution analysis.
  - **Sales by Payment Mode**: Distribution of sales across different payment methods.
  - **Profit by Sub-Category**: Granular profitability breakdown across product sub-categories.
